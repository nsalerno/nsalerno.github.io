core

Full definition (Merriam-Webster): core

Definition

1 : a central and often foundational part usually distinct from the enveloping part by a difference in nature

Remarks

Core code is foundational code that supports application or library development. For example, in an operating system architecture diagram, the kernel's data structures and procedures are the core. The device drivers, user-land API, shell, and utilities are all built around the core and depend on it (either directly or transitively).
